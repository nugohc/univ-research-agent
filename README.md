# 타대학 리서치 에이전트

조사원(서브 에이전트)들과 편집장을 이용해 주제를 조사하고, 보고서 목차·스토리라인까지 확정하는 멀티 에이전트 리서치 시스템입니다.

## 실행 방법

Claude Code에서 한 번의 명령으로 전체 파이프라인이 실행됩니다:

```
/research 타대학 장학 제도
```

(주제를 생략하면 "타대학 장학 제도"로 진행)

## 팀 구성 (`.claude/agents/`)

| 에이전트 | 파일 | 담당 |
|---|---|---|
| 정책 조사원 | `policy-researcher.md` | 교육부·한국장학재단의 정책과 공고 |
| 타대학 조사원 ×3 | `univ-researcher.md` | 주요 거점국립대 / 국내 주요 사립대 / 특수대학의 교내 장학 제도·공지 (동일 정의로 3개 인스턴스 동시 실행) |
| 공시 조사원 | `disclosure-researcher.md` | 대학알리미 장학금 관련 공시 지표 |
| 편집장 | `chief-editor.md` | 조사 결과 종합, 사용자와 논의하며 목차·스토리라인 확정, 보고서 본문 작성·수정 |
| 감사 담당 | `auditor.md` | 보고서 검토(근거 없는 주장·숫자 오류·과장·출처 누락 + 부서 반려 사유 4종), 회차별 검토의견 작성 |

## 동작 방식

1. **조사** — 조사원 5명(정책 1, 타대학 3, 공시 1)이 **동시에** 실행됩니다. 각자 agent-browser CLI로 기관·대학 사이트에 직접 접속해 자료를 수집하고, 조사 시간은 1인당 15분으로 제한됩니다.
2. **저장** — 조사원별 수집 결과가 `research/<날짜>/01~05_*.md` 파일로 각각 저장됩니다.
3. **기획** — 편집장이 결과를 종합해 "반드시 언급할 점 / 언급하되 가릴 점 / 스토리라인 대안"이 담긴 논의용 초안을 만들고, **사용자와 대화하며** 목차와 스토리라인을 확정합니다.
4. **확정** — 확정안이 `research/<날짜>/10_보고서_목차_스토리라인.md`로 저장됩니다.
5. **보고서 작성** — 편집장이 확정 목차대로 `보고서_v1.md`를 작성합니다.
6. **감사-수정 루프** — 감사 담당이 8개 기준(기본 4 + 부서 반려 사유 4)으로 검토해 `검토의견_N회차.md`를 남기고, 편집장이 반영해 `보고서_v(N+1).md`를 씁니다. **최대 3회 왕복** 후 종료(지적 0건이면 조기 종료)하며, 회차마다 GitHub에 커밋·푸시합니다.
7. **버전 비교·출력** — 버전 간 변경 사항을 `버전_비교.md`로 정리하고, 최종 보고서를 `pnu-hwpx-report` 스킬로 한글(hwpx) 파일로 출력합니다.

## 사전 요구사항

- [agent-browser](https://github.com/vercel-labs/agent-browser) CLI 전역 설치: `npm i -g agent-browser && agent-browser install`
- agent-browser 스킬(유저 스코프): `~/.claude/skills/agent-browser/` (CLI에 동봉된 SKILL.md를 복사해 설치됨)
