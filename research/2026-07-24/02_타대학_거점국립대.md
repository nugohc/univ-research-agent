# 타대학 조사 결과: 주요 거점국립대

- 조사 일시: 2026-07-24 15:13 ~ 15:21 (KST)
- 조사 방법: agent-browser CLI(세션 `univ-national`)로 각 대학 공식 장학 안내 사이트 직접 접속·본문 추출
- 조사 대학: 경북대학교(KNU), 전남대학교(JNU), 충남대학교(CNU), 전북대학교(JBNU)

## 핵심 요약

- 4개 거점국립대 모두 "입학성적 우수(수능 기준) 장학 + 재학생 성적장학 + 소득연계/복지 + 근로 + 특별장학"의 공통 골격을 갖추되, 등록금 감면 단위를 "등록금 전액 / 수업료2 / 수업료1" 식 등급제로 운영.
- 최상위 인재 유치 장학 경쟁이 뚜렷함: 경북대 KNU+인재장학금(등록금 전액+학업지원비 500만원), 충남대 CNU Honor Scholarship(등록금 전액+학기당 학업장려금 750만원+생활관 지원+대학원 연계).
- 충남대는 지역인재(대전·충청) 전용 장학과 글로벌 파견 연계형(글로벌엘리트 A/B/C, MEGA CNU GLOBAL)이 특색.
- 전남대는 생활지원형 장학(도전·열정·미래성장·취업더하기·느티나무 등) 포트폴리오가 가장 다양하며, 영·호남 교류학생 장학금(부산대·경북대·울산대 교류생 대상) 운영.
- 공지 게시판은 4개교 모두 교외 재단 장학(화성시인재육성재단, 포스코청암/비전, 정읍시민장학재단 등) 안내가 최신 공지의 대부분을 차지.

## 대학군 공통점과 차이점

**공통점**
1. 등록금 감면형 장학을 "등록금 전액 / 수업료2 / 수업료1" 단위의 등급제로 운영 (전남대 진리 1~4, 전북대 1~5종, 충남대 A/B/C급).
2. 수능 성적 기반 우수 신입생 유치 장학 + 재학 유지조건(15학점·평점 3.3~3.75 수준, 미달 시 중단→탈락) 구조가 동일.
3. 국가장학금·국가근로·국가우수장학(한국장학재단) 연계를 교내 체계 안에 편입해 안내.
4. 국가유공자·북한이탈주민·장애학생·자립준비청년 등 법정·복지 장학은 4개교 모두 등록금 전액 수준으로 유사.
5. 최근 공지 게시판은 교외 재단(화성시인재육성재단, 포스코, 정읍시민장학재단 등) 장학 안내가 대부분 — 공고 소스가 상당히 겹침.

**차이점**
1. 최상위 인재 장학의 현금성 지원 규모: 충남대(학업장려금 학기당 750만원 + 생활관 + 대학원 연계) > 경북대(학업지원비 500만원) 순으로 공격적. 전남대·전북대는 등록금 감면 중심.
2. 충남대는 지역인재(대전·충청 전용, MEGA CNU GLOBAL)와 해외파견 연계(글로벌엘리트)가 강함 — 장학과 국제교류·대학원 진학을 묶은 패키지형.
3. 전남대는 활동·성장 기반 "생활지원형" 장학(도전·열정·미래성장·취업더하기·느티나무)이 가장 다양 — 등록금 감면을 넘어 계획서·활동 기반 지원.
4. 경북대 "장학사정관 장학금"은 갑작스러운 가계 곤란(실직·파산·중증질환·천재지변)을 보직교수 추천으로 즉시 구제하는 사각지대 보완 장치로 독특. 전남대의 "응원장학금"도 국가장학금 탈락자 대상이라는 점에서 유사한 목적.
5. 정보 공개 방식: 경북·전남·충남대는 웹 표로 전 항목 공개, 전북대는 개요만 웹에 두고 세부는 hwp 첨부 — 접근성 격차 존재.

## 편집장에게 전달할 시사점

1. **인재 유치 장학의 '등록금+α' 경쟁**: 거점국립대 상위 장학은 이미 등록금 전액을 넘어 학업장려금(충남대 750만원/학기, 경북대 500만원), 생활관, 해외파견, 대학원 등록금까지 패키지화. 부산대 최상위 장학의 현금성 지원 규모와 직접 비교표를 만들 필요가 있음.
2. **사각지대 구제 장학 모델**: 경북대 장학사정관 장학금(보직자 추천 기반 긴급 구제)과 전남대 응원장학금(국가장학금 탈락자 지원)은 국가장학금 제도의 빈틈을 메우는 벤치마킹 후보.
3. **활동·성장형 장학 다변화**: 전남대의 도전·미래성장·취업더하기·느티나무(국가고시 1차 합격·공모전 수상 보상) 등은 등록금 감면 일변도에서 벗어난 사례 — 학생 성장 인센티브 설계 참고 가치.
4. **지역인재 장학**: 충남대의 대전·충청 전용 장학(4개 학기 전액 + 글로벌 프로그램)은 지역 우수학생 이탈 방지용 — 부산·경남권 인재 대상 유사 설계 검토 소재.
5. **교류 장학 상호성**: 전남대는 부산대·경북대·울산대 교류학생에게 수업료2 전액을 지급(영·호남 교류학생 장학금) — 부산대 측의 상응 제도 여부를 확인해 상호 협력 관점에서 다룰 만함.
